# نمونه‌های نمایشی ابزار SDF برای 3ds Max

پنج نمونهٔ قابل‌ویرایش با نودهای ابزار OSL SDF ایمان شیرانی ساخته شده‌اند.
نسخهٔ ساخت و رندر: **3ds Max 2027.2**.

| فایل | طرح و روش ساخت |
| --- | --- |
| 01_American_Flag.max | پرچم با ۱۳ نوار، کادر آبی و دو آرایهٔ متناوب که مجموعاً ۵۰ ستاره می‌سازند. |
| 02_Gold_Mandala.max | طرح شعاعی طلایی با حلقه‌ها، ۱۶ گلبرگ کپسولی، ۱۲ لوزی و ۶۴ نقطهٔ دور طرح. |
| 03_Perforated_Panel.max | پنل با گوشهٔ گرد و ۳۵ سوراخ، قاب، پیچ‌های گوشه و نشانگرهای پایین. |
| 04_Art_Deco_Pattern.max | الگوی تزئینی از قوس‌های تو‌در‌تو و آرایه‌های جابه‌جاشده. |
| 05_Compass_Emblem.max | نشان قطب‌نما از دو ستارهٔ چهارپر، حلقه‌ها و ۴۸ خط شعاعی. |

## استفاده

فایل مکس را باز کن. هر نمونه یک صفحه، متریال پارامتریک و دوربین تست Scanline دارد.
صفحه را انتخاب کن و متریالش را وارد Slate کن تا زنجیرهٔ نودها را ببینی.
متریال نمونه در اولین اسلات Material Editor هم قرار دارد.

کد شیدرها، همراه با هدر Copyright و License، داخل فایل مکس ذخیره شده است.
برای باز کردن نمونه‌ها به درایو G سازنده یا تصویر تکسچر خارجی نیاز نیست.
این کدها نسخهٔ ذخیره‌شده در صحنه هستند؛ با تغییر فایل‌های OSL نصب‌شده، خودکار آپدیت نمی‌شوند.

## نکته‌های ساخت

ستاره‌های ضلع‌مستقیم از ترکیب نودهای Triangle و یک دایرهٔ مرکزی ساخته شده‌اند.
از SDF_Star فعلی استفاده نشده، چون ضلع‌های آن در خروجی فعلی منحنی هستند.
کد نودهای اصلی برای ساخت این نمونه‌ها تغییر نکرده است.

نودهای کمکی Demo_Color_Mix برای ترکیب رنگ‌ها و Demo_Aspect_Compensation در پرچم
برای اصلاح نسبت طول به عرض استفاده شده‌اند. ساخت شکل‌ها، تکرارها و عملیات Boolean
با نودهای ابزار انجام شده است.

این نمونه‌ها **ماسک متریال پارامتریک** هستند؛ مش هندسی تولید نمی‌کنند.
ترکیب میدان‌های فاصله با Union، الزاماً فاصلهٔ دقیق تا مرز را در تمام ناحیه‌های هم‌پوشانی حفظ نمی‌کند.
نمونهٔ پرچم برای نمایش چیدمان است و مشخصات تأییدشدهٔ تولید پرچم محسوب نمی‌شود.

برای تغییر طرح، Count و Cell Spacing آرایه‌ها، Repetitions و Placement Radius تکرار شعاعی،
Size و Radius شکل‌ها و رنگ نودهای ترکیب رنگ را تغییر بده.
